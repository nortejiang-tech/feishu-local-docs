## 限制

HTML 只能渲染已经取得的内容。静态公式使用缓存，缺缓存时显示公式；部分数字格式使用原值。画板为基础结构预览，多维表格为静态数据，甘特图等完整视图尚未恢复。字体依赖本机。电子表格 HTML 总位置上限 150000、文件上限 32 MiB，超限或合并冲突整次拒绝，避免生成截断副本。幻灯片未纳入当前交付。

## 冻结方法与恢复

以附注 Git 标签 `v0.2.8` 固定提交。`source-lock.json` 列出源码/测试/构建配置的逐文件 SHA-256；`artifact-lock.json` 记录本地已签名 App 与扩展产物的哈希，二进制本身不上传。哈希清单是完整性依据，不代表远程信任认证。依赖用现有 npm lockfile 固定。

需要复现时，签出 `v0.2.8` 到独立目录，安装锁定依赖并运行 README 的构建命令；构建工具版本和临时签名变化可能导致二进制哈希不同。资料库位于用户 Application Support，不属于源码仓库，也不随 Git 回退。

本次只进行版本整理和发布，没有新调用 EVO-Coder。Git 提交/标签/推送按用户规则交给 Luna 执行；Planner 完成范围审查和最终远端读回。
