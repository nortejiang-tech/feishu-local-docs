# 数据处理说明（0.4.1 开发候选版）

应用与扩展没有开发者运营的正文上传服务，不内置遥测或广告。桌面版在当前用户的 `~/Library/Application Support/LocalDocs/` 保存资料库、历史版本、最近删除、收到的副本、HTML、任务确认和接收配置备份。网页版将资料保存在当前浏览器的 IndexedDB；清除浏览器站点数据会移除这份资料库，建议显式导出备份。

Chrome 扩展使用 `activeTab`、`scripting`、`nativeMessaging`、`storage`。点击时读取当前页面；未申请常驻全站访问、Cookie 或浏览历史权限。资源读取与飞书来源平台交互，沿用当前页面已获准访问的内容，服务器拒绝时记录缺口，不改变权限。私有文档正文不保存在扩展任务元数据里；任务记录包含任务 UUID、来源路径散列、状态、进度及文件哈希。资料标题会在本地弹窗中显示。

本地文件可能含原始内容、图形节点、资源标识和采集上下文，属于用户资料。将文件保存到 iCloud 或其他同步目录会由相应服务同步；本应用不会承诺这些第三方服务的隐私、版本合并或加密能力。默认资料库在本机，不做透明的跨 Mac 同步。

HTML 禁用脚本与联网加载，内嵌已取得的图片。文档中的外部链接仍可由用户主动打开。保存的文件没有额外的应用层加密，应依赖系统账号和磁盘保护。

飞书回导入口默认关闭，打开入口不自动上传；用户主动执行回导时，桌面集成会把转换后的 Office 文件交给已配置的飞书连接，创建新副本。真实无损回导仍待验收。

“最近删除”仅是可恢复移动。历史记录每份文件最多保留 10 个版本、合计约 64 MB；超过上限的旧历史记录会自动清理，当前文件与“最近删除”文件不参与此清理。当前版本不自动清空“最近删除”；文件夹结构和副本应由用户自行备份。卸载应用前可先导出需要的文件。

本项目与飞书/Lark 没有官方关联。只处理用户拥有或已获准保存的资料。
