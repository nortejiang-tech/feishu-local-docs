# 0.4.0 开发候选版 · 2026-10-25

整体完整保真验收：**PENDING**。此版本可用于开发验证，不标记为已完成飞书全部功能的正式发行版。

## 变更

- 桌面资料库首次载入只返回摘要，按需载入正文；文档和电子表格编辑器分开加载。
- 本地标题搜索、文件夹筛选与分配、可恢复的最近删除、Finder 文件位置和统一导出菜单。
- 原生资料库使用跨进程锁和原子写入；相同/较旧修订拒绝覆盖不同内容，删除后的迟到保存不会复活文件。打开外部副本创建独立条目。发生保存冲突仍可导出当前编辑副本。
- Chrome 保存任务元数据可跨弹窗和服务进程重启恢复；同源重复点击复用任务，确认结果前不自动新建副本。来源切换停止旧任务交付；原生写入阶段提供结果重查。
- 保存可编辑副本时可同时生成 HTML，默认选择两者。两种文件分别计算哈希；HTML 未完成或校验不一致时不宣告配对保存成功。App 可以从原始副本重建与任务计划一致的 HTML。
- 嵌入资源按队列读取，设数量/总字节/时长限制；只对短暂失败重试一次，权限拒绝与格式错误保留明确缺口。停止后续读取不会撤销已发送的单项页面请求。
- 设置页提供本机接收配置检查、修复和配套插件目录。只检查本地配置，不将它冒充为 Chrome 安装状态或端到端成功。移动应用后修复配置会备份自身原配置，不覆盖其他来源的接收配置。
- 飞书回导入口默认关闭，显式开启后仍受对象支持范围限制。工作表检查与 HTML 保留逐表采集计数，明确显示加载覆盖未知。
