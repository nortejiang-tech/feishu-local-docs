# 0.4.1 开发候选版 · 2026-10-26

P1 整体验收：**PENDING**。本次完成本地并发保护、历史版本与 HTML 样式继承；未宣告完整资源采集或可编辑无损回导完成。v0.2.8 冻结版本继续保留。

## 本次改动

- 保存必须匹配打开时确认的文件内容哈希。修订号增加不能覆盖其他窗口已保存的不同版本；完全相同的重复保存仍可确认成功。
- 自动保存失败显示具体原因，并提供“保存当前编辑副本”。发生冲突仍可导出当前窗口的草稿。
- 每次替换已保存文件前保留上一版本。每份文件最多保留 10 个版本、合计约 64 MB；“导出 → 历史版本 → 打开为独立副本”创建新的资料库条目。
- 桌面历史记录保存失败时不替换当前文件。浏览器历史记录和当前文件在同一 IndexedDB 事务提交。历史副本保留采集来源，解除原浏览器交付任务的关联。
- HTML 采用与当前安装的 Univer 默认一致的样式优先级：工作表默认、列、行、主题和单元格。显式零值和清空值保留，嵌套样式按整体替换；缺失引用明确提示。
- 表格单元格内的连续编号项目按兄弟顺序合并为列表，嵌套项目留在父项目内；分隔段落会开始新的列表。真实样本 137 个编号条目全部保留，20 张普通表格和 19 张图片保持。
- 小窗口关闭侧栏时同时隐藏交互元素；历史版本工具栏允许换行。

## 验证

- macOS 自动回归 **345/345 PASS**。原生测试实际编译 Swift，在独立临时目录验证内容哈希冲突、旧版本字节恢复、历史数量上限、路径检查、删除恢复，以及历史目录不可写时当前文件保持不变。没有模拟整个系统磁盘耗尽或突然断电。
- 真实浏览器 IndexedDB 双窗口测试：窗口 A 保存后，窗口 B 的首次及更高修订号保存均拒绝覆盖；B 的草稿成功导出独立 `.localdoc`；重新载入确认 A 的内容仍保留。
- 真实浏览器历史恢复：上一版本列出并打开为独立可编辑副本，当前版本继续保留。
- 真实约 5 MB 文档副本打开：20 张普通表格可显示；19 张图片均已解码；另有两个 Base 数据表。可从该文档切换到其他文件及历史版本。此结果不证明图像原始质量、画板样式或 Base 视图保真。
- 现有已安装 Chrome 扩展经 Native Messaging 产生了新的真实采集副本，包含 2327 个区块。该结果属于原先安装版本，不能替代本候选版 App/扩展配对的端到端验收。
- 原有 22 份本地文件哈希复核保持不变。没有修改飞书原文，没有生成云端回导副本。

本地构建为 Apple Silicon、macOS 13+，ad-hoc 签名校验通过。GitHub CI 另行以提交对应运行结果为准；签名校验不代表 Developer ID 或公证。

## 文件、迁移与回退

`.localdoc` 格式保持 v2，打开外部副本仍创建独立条目。桌面历史记录在本机 `LocalDocs/History/`，不自动随导出的单文件迁移。

浏览器资料库从 schema 2 升到 3，新增历史存储。升级遇到旧窗口占用时会明确提示；关闭旧窗口后重试。回退旧网页版前请导出所需文件；旧版不能直接打开更新后的浏览器资料库。桌面当前文件可继续用冻结版读取，但旧版不具备本次内容哈希冲突保护，避免同时编辑同一文件。

源码仓库不包含真实采集正文、用户截图、私有日志、应用二进制或连接配置。
